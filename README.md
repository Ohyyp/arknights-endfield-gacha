# 明日方舟：终末地 抽卡规划工具

[英文版](README.en.md)

这是一个基于 C++20 编写的高性能命令行工具 (CLI)，旨在辅助玩家优化并规划他们在《明日方舟：终末地》中的抽卡策略。

## 核心功能

- **双引擎计算架构**:
  - **蒙特卡罗模拟引擎**: 通过海量模拟精确处理复杂的边缘情况（如 30/60 抽免费赠送奖励）。
  - **动态规划精确引擎 (DP)**: 利用贝尔曼方程和马尔可夫更新过程，计算绝对完美的数学期望效用。
- **无限远景残值评估**: 量化你当前手中剩余的小保底在无限长的未来卡池时间线中的“跨池残余价值”。
- **自定义角色权重**: 通过简单的 TOML 配置文件，为常驻和限定角色灵活分配 0.0-1.0 的效用权重。

## 环境要求

- 支持 C++20 的编译器（支持 Clang 与 GCC）。
- CMake (版本 3.14 或以上)。

*注：项目依赖（`toml++` 和 `CLI11`）会在 CMake 配置阶段通过 `FetchContent` 自动下载并链接，无需手动安装任何包管理器。*

## 编译指南

# 快速构建

本工程提供 CMake Presets 快速构建支持。

```bash
# 生成并编译 (以 Clang 为例)
cmake --preset clang
cmake --build --preset clang

# 运行 CLI 验证引擎
./build/clang/EndfieldGacha.exe --help
```

请参阅 `docs/` 目录获取详细的数学设计文档。
